# Security Policy

## Supported Versions

Security fixes are handled for the latest published version of
`@standhigher/charts`.

## Reporting a Vulnerability

Please do not open a public GitHub issue for sensitive security reports.

Report security concerns to the repository maintainers with:

- Package name and version.
- A short description of the issue.
- Reproduction steps or a minimal example when possible.
- Whether the issue affects runtime behavior, published package contents, or the release workflow.

If the report is valid, maintainers will coordinate a fix, publish a patched npm
version, and document the change in `CHANGELOG.md`.
